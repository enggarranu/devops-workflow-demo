Rollback, diuji di run ini Rollback, exercised in this run

Rollback bukan script yang cuma ada di repo. Tiap run mendeploy dua build, lalu rollback ke build pertama, lalu membuktikan lewat HTTP bahwa build pertama benar-benar dilayani kembali. Rollback is not a script that merely exists in the repo. Every run deploys two builds, rolls back to the first one, then proves over HTTP that the first build really is being served again.

On Windows there is one more operation after the pointer moves, Restart-WebAppPool, and that operation is what makes the number above far larger than on Linux. For a static site like this one, most of its value is precaution: stage 7 on the main page shows a content change is already visible on the first request. This number is wall time on a GitHub runner, not an SLA promise: it is useful for comparing the two paths on this page, not as a target.
